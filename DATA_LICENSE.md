# Data License and Availability

The ABM-IRM source code and repository documentation are released under the MIT License. The prepared input data require separate attention because they may be derived from third-party statistical and geospatial sources.

Before making the repository public, confirm whether each prepared data file can be redistributed under the terms of its original source. The manuscript/supplement workflow references data sources including ESRI Japan, e-Stat, IPSS, GSI/MLIT, OpenStreetMap, and BODIK.

If any source does not allow redistribution of derived files, remove the restricted prepared data from the public repository and provide instructions for users to obtain or regenerate the required files.

Recommended public-release wording:

> Code and documentation are licensed under the MIT License. Input data are provided only where redistribution is permitted by the original data sources. Users are responsible for complying with the terms of the source datasets when applying ABM-IRM to new regions or rebuilding the prepared inputs.
